## 실제 Chrome 브라우저 항목별 검증

연결된 데스크톱의 설치된 Chrome에서 최종 `app.js`를 로컬로 열고 CDP를 사용해 아래 흐름을 실제 실행했습니다. 새로운 브라우저·패키지를 설치하거나 외부에 배포하지 않았습니다.

- 목록·카테고리·검색, 비회원 글쓰기의 데모 로그인 요구
- 로그인 창 닫기와 실제 Escape 입력으로 취소, 취소된 작업이 나중에 재개되지 않음
- 글쓰기 요청 후 데모 로그인 시 작성 화면 재개와 입력 포커스
- 게시글·댓글 작성, script 문자열을 실행하지 않고 글자 그대로 표시
- 게시글·댓글 신고, 댓글 숨김/복원, 게시글 숨김/복원, 신고 기각
- 명시적 저장 선택 후 새로고침 유지, 데모 로그인 신원은 저장하지 않음
- 초기화 취소/확정, 손상된 저장 데이터 복구, 저장소 쓰기 차단과 차단 상태의 초기화
- 데스크톱 1440px 및 모바일 모의 뷰포트 390px 렌더링: 가로 넘침 없음
- 실제 렌더링한 데스크톱·모바일·운영자 화면 PNG를 시각 확인 후 제공

## 검증 방식과 남은 확인

클라우드 환경의 Chromium은 Unix 소켓 제한으로 실행되지 않았고, 데스크톱에는 Playwright 패키지가 없어 **`tests/browser.cjs` 전체 실행은 하지 않았습니다**. 위 결과는 설치 Chrome을 통한 별도의 CDP 항목별 검증 결과입니다. 첫 CDP 스크립트의 마지막 시작 시점 저장 차단 주입이 적용되지 않아 해당 테스트 준비 단계가 실패했습니다. 쓰기·삭제 차단은 같은 페이지에서 직접 오류를 주입하는 별도 검사로 통과했으며, 이를 전체 스크립트 일괄 통과로 표기하지 않습니다. Playwright 스크립트의 문법 검사와 실제 Chrome 흐름 검증을 구분합니다.

`tests/browser.cjs`는 정상적인 Playwright/Chromium 개발 환경에서 같은 흐름과 화면 캡처를 반복하기 위한 스크립트입니다. 저장소 접근 자체가 시작 시점부터 차단된 로드 시나리오, Safari/Firefox, 실제 모바일 기기, 스크린리더, 모든 키보드·네비게이션 조합은 확인하지 않았습니다. 저장소 쓰기·삭제 차단은 실행 중 같은 페이지에 오류를 주입해 별도로 확인했습니다.

## 범위 밖
