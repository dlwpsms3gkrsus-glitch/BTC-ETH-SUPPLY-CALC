CryptoFlow 소개

CryptoFlow는 “비트코인과 이더리움은 실제로 얼마나 늘어나고 있을까?”라는 질문에 데이터로 답하기 위해 만든 사이트입니다.

만든 이유

뉴스와 커뮤니티에는 “반감기로 공급이 줄었다”, “이더리움은 디플레이션 자산이다” 같은 이야기가 많지만, 원하는 기간을 정해 실제 숫자를 확인할 수 있는 도구는 찾기 어려웠습니다. 그래서 공개된 블록체인 데이터를 매일 자동으로 받아와, 누구나 날짜만 고르면 공급 변화를 확인할 수 있는 계산기를 만들었습니다.

제공하는 것

  • 공급량 계산기: 시작일과 종료일을 고르면 BTC·ETH 공급 증가량, 증가율, 누적 차트를 보여줍니다.
  • 현물 ETF 자금 흐름: 비트코인·이더리움 현물 ETF의 일별 자금 유입·유출을 차트로 보여줍니다.
  • 공급량 가이드: 반감기, 소각, 지분증명 전환 등 공급과 관련된 개념을 실제 데이터와 함께 설명합니다.

데이터와 운영 방식

공급량 데이터는 Coin Metrics Community API에서 가져오며, GitHub Actions 자동화로 매일 한국 시간 오후 6시 10분에 갱신됩니다. 사이트의 모든 코드는 GitHub 저장소에 공개되어 있어 계산 방식을 누구나 확인할 수 있습니다. 변경 내역은 릴리즈 노트에 기록합니다.

원칙

  • 데이터 우선: 의견보다 확인 가능한 숫자를 먼저 보여줍니다.
  • 투자 권유를 하지 않습니다: 특정 자산의 매수·매도를 추천하지 않으며, 가격 전망을 제공하지 않습니다.
  • 오류는 바로 고칩니다: 잘못된 정보나 계산 오류를 발견하시면 문의로 알려 주세요.

운영자

CryptoFlow는 업무 자동화와 데이터 처리에 관심이 많은 개인 개발자가 운영합니다. 개발과 블록체인 데이터에 대한 이야기는 운영자 블로그에서도 볼 수 있습니다.
